👁️ "Deep Learning & Computer Vision"
The system utilizes a custom 4-block CNN named AgriNet, featuring Inverted Residual Blocks (AgriBlocks), Depthwise Separable Convolutions, and a final fully-connected classifier. Explainability is achieved via Grad-CAM heatmaps generated directly from the final convolutional layer gradients.

🌿 "Plant Disease Detection System with Domain Adaptation"
Classifies 38 categories across 14 plant species. To bridge the "Lab-to-Field" domain gap (studio-lit PlantVillage images vs. noisy field PlantDoc images), we implemented mixed-domain training using a custom class-mapping pipeline, achieving 96.14% validation accuracy under real-world conditions.

🤖 "Dual AI Layer"
Integrates disease classification (AgriNet) with a context-grounded agricultural assistant (RAG) powered by FAISS, Sentence-Transformers, and the Groq API (Llama-3.1-8b-instant), ensuring verified, hallucination-free advice.

SLIDE 2: INTRODUCTION & BACKGROUND
===============================================================================
- AgriVision 2.0 is a full-stack, ML-powered web application for real-time plant disease diagnosis using leaf images.
- Agriculture employs over half of India's workforce, but biological pathogens cause annual crop losses of 15% to 20%.
- Traditional diagnosis relies on visual inspection, which is subjective and slow. Access to agronomists in rural areas is limited.
- Our solution automates detection using a lightweight, edge-ready CNN named "AgriNet" coupled with a local RAG advisor.
- Bridges the "Domain Gap" (lab-trained AI failing in natural farm environments) through mixed-domain training.

===============================================================================
SLIDE 3: PROBLEM STATEMENT
===============================================================================
- Standard agricultural CNN models are trained on clean, studio-lit laboratory datasets (e.g., PlantVillage) and fail in natural field conditions due to covariate shift.
- Access to professional agricultural extension workers is slow in remote rural communities.
- Common LLM chatbots suffer from hallucinations and offer unreliable treatment advice.
- Prior project versions used heavy, pre-trained transfer learning architectures (like EfficientNet or ResNet) which do not satisfy the academic requirement for a custom major project design.

SLIDE 6: DATASET INGESTION & PREPROCESSING
===============================================================================
- PRIMARY CORPUS: PlantVillage (54,305 lab-captured images, 38 classes, 14 species).
- SECONDARY CORPUS: PlantDoc (2,231 real-world farm photos mapping to 27 classes).
- CLASS MAPPING:
  - Built custom MappedPlantDocDataset to remap PlantDoc naming conventions to exact PlantVillage class indices (26 of 27 classes mapped successfully).
  - Merged datasets using PyTorch's ConcatDataset, creating a unified set of 56,536 images.
- PREPROCESSING PIPELINE:
  - Input resizing to $224 \times 224$ pixels.
  - Pixel scaling to $[0, 1]$ and normalization using ImageNet stats ($\mu=[0.485, 0.456, 0.406]$, $\sigma=[0.229, 0.224, 0.225]$).
  - Augmentations: RandomHorizontalFlip, RandomRotation(±20°), and ColorJitter.

SLIDE 7: CUSTOM CNN BACKBONE: AGRINET
===============================================================================
- AgriNet is built to be lightweight and fast for edge deployment.
- Core: Depthwise Separable Convolutions & Inverted Residual Blocks (AgriBlocks).
- Parameter Reduction:
  - Factorizes standard convolutions into a spatial depthwise filtering stage and a channel-wise pointwise projection stage.
  - Reduces mathematical complexity by a factor of 8 to 9 using a standard $3 \times 3$ kernel:
    Cost Ratio = $(1 / N) + (1 / D_K^2)$
- AgriBlock Pipeline:
  - Expand ($1 \times 1$ pointwise conv with expansion ratio $t$) → Filter ($3 \times 3$ depthwise conv) → Project ($1 \times 1$ pointwise conv, omitting non-linear activation to create a linear bottleneck).
  - Skip connection added when stride=1 and input/output channels match.

SLIDE 8: SYSTEM DATA FLOW (DFD)
===============================================================================
- LEVEL 0 (CONTEXT LEVEL):
  - User submits leaf image and RAG queries.
  - The decoupled system processes inputs and returns crop predictions, confidence scores, Grad-CAM heatmaps, and context-grounded treatment advice.
- LEVEL 1 (FUNCTIONAL DECOMPOSITION):
  - Process 1 (Authentication): Verifies user credentials in PostgreSQL and issues JWTs.
  - Process 2 (Prediction): Feeds images to AgriNet, logs results, generates Grad-CAM overlays.
  - Process 3 (RAG Advisor): Embeds queries, searches the FAISS index, and generates answers using Groq's Llama-3.1 API.

SLIDE 9: DECOUPLED PROJECT ARCHITECTURE
===============================================================================

  - Frontend (Next.js 14 + React): Presentation layer with glassmorphic dashboards, interactive history logs, and PDF generation.
  - Backend (FastAPI + Python 3.11): REST API serving predictions, authentication, history, and RAG chats.

SLIDE 11: RAG CHAT ASSISTANT PIPELINE
===============================================================================
- Knowledge Base: Official agricultural extension manuals (Tomato, Potato, Maize, Apple, and general Integrated Disease Management guides).
- Vectorization:
  - LangChain's RecursiveCharacterTextSplitter chunks text into 1,000 characters with 200-character overlaps.
  - Dense 384-dimensional embeddings generated via `sentence-transformers`.
- Indexing & Retrieval:
  - Vector vectors indexed locally using Facebook AI Similarity Search (FAISS).
  - Matches queries using Cosine Similarity ($k=3$).
- Constrained Generation:
  - Chunks sent to Llama-3.1-8b-instant via Groq API.
  - Strict system prompt prevents hallucinations: if information is missing in context, the LLM states that it cannot answer.

SLIDE 15: EXPLAINABLE AI (GRAD-CAM OVERLAYS)
===============================================================================
- The black-box nature of deep neural networks raises adoption barriers for farmers.
- Grad-CAM targets the feature maps of the final convolutional layer of AgriNet.
- Mathematically isolates features that increase the model's confidence for the target class:
  $L^c_{\text{Grad-CAM}} = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$
- Outputs a colorized overlay highlighting leaf lesions (hot spots) while ignoring background soils, shadows, or dry twigs.
- Integrated into the web UI so visual highlights are displayed side-by-side with diagnostic scores.
